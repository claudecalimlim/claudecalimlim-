## 🚀 Featured Projects

### 🤖 [Gemini LLM Simulator](https://github.com/claudecalimlim/Gemini-LLM-Simulator)
A Python GUI-based chatbot powered by the Google Gemini API. Demonstrates LLM conversation handling using Tkinter. Built to explore how large language models can be integrated into lightweight desktop applications.  
`Python` `Tkinter` `Google Gemini API` `LLM`

---

### 📊 [T1 vs KT — Machine Learning Prediction](https://github.com/claudecalimlim/T1-vs-KT-Statistical-Dataset-for-Machine-Learning-Prediction)
A structured and cleaned statistical dataset built from T1 vs KT Rolster matches across the 2025 LCK Season (Cup, Split, and Road to MSI stages). Designed for machine learning prediction modeling and data analysis practice.  
`Python` `Machine Learning` `Data Analysis` `Statistical Dataset`

`HTML` `CSS` `JavaScript` `Systems Design`
